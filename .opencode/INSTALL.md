# Installing Jules Orchestrator for OpenCode

## Prerequisites
- [OpenCode.ai](https://opencode.ai) installed

## Installation

Add this plugin to your OpenCode configuration:

```json
{
  "plugin": [
    "jules-orchestrator@git+https://github.com/nur-srijan/jules-mcp.git"
  ]
}
```

The `jules-orchestrator` skill will be automatically discovered in `./skills/`.
